


Задача: реализовать панель фильтрации товаров.

Компонент: `apps/web/src/features/product-filter/ui/ProductFilterPanel.tsx`
Импортируется в: `CatalogPage`

API: реализовано через спеку.

Референс по UX (https://pneumax.ru, раздел «Каталог»):
- фильтры сгруппированы по категориям, каждая секция сворачивается
- диапазон "от-до" для числовых характеристик (например, давление)
- чекбоксы для категориальных значений (бренд, тип)
- счётчик найденных товаров обновляется до применения фильтра

Требования:
- состояние фильтров синхронизируется с query-параметрами URL
- используй существующий паттерн хука данных, как в 
  `features/categories/use-categories.ts`
- стили — Tailwind, токены из @theme, без произвольных значений
- адаптив: на мобильном фильтры уходят в выезжающую панель
